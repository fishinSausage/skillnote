# 스킬노트 발표 웹페이지

단일 HTML 파일로 구성된 발표용 웹페이지입니다.  
PDF 슬라이드 뷰어와 스킬노트 프로토타입(가상 휴대폰)을 한 페이지에서 확인할 수 있습니다.

## 파일 설명

- **presentation.html**  
  모든 기능이 포함된 단일 HTML 파일입니다.  
  - PDF 업로드 및 페이지 뷰어  
  - 스킬노트 프로토타입 (가상 휴대폰 프레임)  
  - 전체화면 기능  

  외부 의존 파일 없이 이 파일만으로 동작합니다.  
  (PDF 뷰어는 인터넷 연결 시 CDN에서 pdf.js를 불러옵니다.)

## 사용 방법

1. `presentation.html` 파일을 브라우저로 엽니다.  
   (더블클릭 또는 브라우저에 드래그)
2. 상단 탭에서 원하는 화면을 선택합니다.
   - **PDF 슬라이드**: PDF 파일을 업로드해서 슬라이드처럼 볼 수 있습니다.
   - **스킬노트 데모 (휴대폰)**: 가상 휴대폰 화면에서 스킬노트 프로토타입을 체험할 수 있습니다.
3. **전체화면** 버튼을 누르면 현재 보고 있는 화면이 전체화면으로 전환됩니다.  
   (종료는 버튼 또는 `Esc` 키)

## 배포 (GitHub Pages 등)

이 파일 하나만 저장소에 올리면 됩니다.  
GitHub Pages를 사용할 경우 파일 이름을 `index.html`로 변경하면 루트 주소로 바로 열립니다.

## 참고

- 스킬노트 데모는 원본 프로토타입을 그대로 내장했습니다.
- 활동 기록 등 데이터는 브라우저 localStorage에 저장됩니다.
