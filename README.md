# 스킬노트 발표 웹페이지

PDF 슬라이드와 스킬노트 프로토타입을 한 페이지에서 오프라인으로 발표할 수 있습니다.

## 파일 설명

- **presentation.html** — 발표 화면과 내장 스킬노트 데모
- **skillnote/pdfjs/** — 오프라인 PDF 표시에 필요한 파일. 발표 HTML과 함께 두고 폴더 구조를 유지합니다.

## 사용 방법

1. ZIP을 모두 압축 해제한 다음 `presentation.html`을 Chrome이나 Edge에서 엽니다.
2. 상단 탭에서 원하는 화면을 선택합니다.
   - **PDF 슬라이드**: PDF 파일을 업로드해서 슬라이드처럼 볼 수 있습니다.
   - **스킬노트 데모 (휴대폰)**: 가상 휴대폰 화면에서 스킬노트 프로토타입을 체험할 수 있습니다.
3. PDF를 연 뒤 **전체화면**을 누르면 조작 버튼을 숨기고 슬라이드를 화면에 맞춥니다. `→`, `Space`, `Enter`는 다음 장, `←`는 이전 장, `Esc`는 전체화면 종료입니다.
4. PDF 발표를 마치면 `Esc`를 누르고 **스킬노트 데모(휴대폰)** 탭으로 이동합니다.

## 배포 (GitHub Pages 등)

발표 HTML과 `skillnote/pdfjs/` 폴더를 함께 올립니다.
GitHub Pages를 사용할 경우 파일 이름을 `index.html`로 변경하면 루트 주소로 바로 열립니다.

## 참고

- 스킬노트 데모는 원본 프로토타입을 그대로 내장했습니다.
- 활동 기록은 IndexedDB에, 설정은 브라우저 로컬 저장소에 유지됩니다. 발표 데모와 단독 앱은 별도 저장 공간을 사용합니다.
- 입력란 밖에서 `R`과 `E`를 함께 누르면 현재 앱의 기록과 설정이 예시 상태로 돌아갑니다. 발표 화면에서는 `데모 초기화` 버튼도 같은 동작을 합니다.
